# 任务管理控制器

## POST 创建 SQL 生成任务

POST /api/task/create

<p>
关联 Excel 文件与表结构，初始状态为 PENDING。
</p>

> Body 请求参数

```json
{
  "fileKey": "string",
  "schemaKey": "string",
  "dbType": "string",
  "batchSize": 1000
}
```

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|[CreateTaskRequest](#schemacreatetaskrequest)| 否 |none|

> 200 Response

```json
{
  "code": 0,
  "message": "string",
  "data": {
    "taskKey": "string",
    "status": "string",
    "fileKey": "string",
    "schemaKey": "string",
    "dbType": "string",
    "totalRows": 0,
    "batchSize": 0,
    "errorMessage": "string"

  "timestamp": 0

```

|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|[ResultTaskDetailVO](#schemaresulttaskdetailvo)|

# SQL 生成控制器

## POST 触发 SQL 生成

POST /api/generate/start

<p>
totalRows ≤ 5000：同步返回 sqlContent；超出则立即返回 GENERATING 状态，前端轮询结果。
</p>

> Body 请求参数

```json
{
  "taskKey": "string"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|[GenerateSqlRequest](#schemageneratesqlrequest)| 否 |none|

> 返回示例

> 200 Response

```json
{
  "code": 0,
  "message": "string",
  "data": {
    "taskKey": "string",
    "status": "string",
    "sqlContent": "string",
    "downloadUrl": "string"
  },
  "timestamp": 0
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|[ResultGenerateResultVO](#schemaresultgenerateresultvo)|
